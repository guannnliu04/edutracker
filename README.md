# 線代每日測驗(研究所線性代數)

手機優先(iPhone Safari / 主畫面 App)的每日五題測驗。React + TypeScript + Vite + Supabase,部署到 Vercel。

## 功能(MVP)

- **每日五題**:3 題基礎觀念/舊錯題、1 題最新章節、1 題作業風格;同一天重新整理題目與選項順序不變
- 點選 A/B/C/D 作答,每題可勾「不確定」;**五題全部提交後**才顯示答案與逐題解析(伺服器端評分,提交前連資料庫都讀不到答案)
- 自動記錄日期、題目、觀念、對錯、不確定、錯誤類型(提交後自己標:觀念/計算/粗心/猜的)
- 答錯 → 排定隔日、3 日、7 日複習,到期時優先出同觀念的另一題(變式)
- **錯題與弱點**:近 7 天統計、觀念弱點 Top 10(含遺忘次數)、錯題紀錄與解析、複習排程
- **讀書計畫**:今日項目新增/勾選/刪除、完成進度、線代五題狀態
- **登入**:Supabase Email + 密碼(單人系統),換手機資料仍在
- **PWA**:可加入 iPhone 主畫面;通知連結 `/quiz` 直接進當天測驗
- 題目來源:全部標示「自編題」;標為歷屆作業必須附出處(前端測試與資料庫約束都會檢查)

部署與設定步驟見 [docs/SETUP.md](docs/SETUP.md)。

## 尚未做

- 網站自行發送通知(PWA Web Push)— 目前由 ChatGPT 自動化發送連結

## 開發

```bash
npm install
npm run dev        # 未設定 Supabase 變數時使用「本機示範模式」
npm test           # 題庫驗證、選題/複習流程、弱點統計
npm run test:db    # 資料庫權限與評分(需本機 postgresql-16 伺服器)
npm run build
```

新增題目時,計算題請先用程式(numpy)驗過答案;解析不可使用「選項 A/B」這類位置用語(選項會被打亂)。
